Article Quiz settings

Get a key at console.anthropic.com. The key stays in this browser's extension storage. The extension sends it only to api.anthropic.com.

Choose from the list or type any model ID. Leave it empty to use claude-haiku-5-5.

What the extension sends

When you open the quiz, the extension reads the text of the current tab and sends it to the Anthropic API to write the questions. When you check a written answer, it sends the article text and your answer again. It sends nothing anywhere else.
